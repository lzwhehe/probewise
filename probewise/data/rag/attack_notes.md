# ATT&CK 技术说明（自行整理的简述，技术编号引用自 MITRE ATT&CK®）

## T-T1078 Valid Accounts（有效账号）
攻击者使用窃取或猜测得到的合法账号登录，绕过边界防护。检测重点是登录上下文的异常：陌生设备、异常地点、旧认证协议、MFA 疲劳。防御上依赖 MFA、条件访问和会话吊销能力。

## T-T1204 User Execution（用户执行）
攻击者诱导用户运行文件，例如伪装成发票、字体包、驱动的可执行程序。检测重点是从下载目录或临时目录启动的未签名程序，以及在全网罕见的文件。

## T-T1071 Application Layer Protocol（应用层协议通信）
恶意程序借助 HTTP、DNS 等常见协议与控制端通信，常表现为固定间隔的外联。区分正常遥测的关键是目的地的流行度、信誉和发起进程。

## T-T1098 Account Manipulation（账号操纵）
攻击者通过新建账号、修改组成员关系等方式维持或提升权限。没有对应变更流程的特权变更，是最直接的检测线索。

## T-T1567 Exfiltration Over Web Service（经 Web 服务外传数据）
攻击者或内部人员把数据上传到网盘、协作平台等外部 Web 服务。检测需要结合流量基线、目的地性质和人员状态（如离职流程）。

## T-T1566 Phishing（钓鱼）
攻击者通过邮件附件或链接投递恶意内容。办公软件打开附件后派生脚本解释器，是附件型钓鱼的典型迹象。

## T-T1059 Command and Scripting Interpreter（命令与脚本解释器）
攻击者借助脚本解释器执行后续操作。判断时要看谁启动了解释器、解释器做了什么，以及同一行为在组织内是否普遍。

## T-T1190 Exploit Public-Facing Application（利用面向公网的应用）
攻击者利用对外 Web 应用、中间件的漏洞获得初始访问，常见手法包括 SQL 注入、表达式注入（OGNL / SpEL / JNDI）、目录穿越和文件上传。研判要区分「攻击尝试」和「攻击成功」：大多数尝试返回 404 或 400，响应中出现敏感文件内容或命令回显才说明可能成功。

## T-T1595 Active Scanning（主动扫描）
攻击者批量探测目标的资产和漏洞，特征是脚本类 User-Agent、请求不存在的路径、短时间内命中大量不同规则。单位自己授权的漏洞扫描也有同样特征，需要结合扫描器白名单判断。
